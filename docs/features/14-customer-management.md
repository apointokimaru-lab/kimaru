# 14. 顧客管理・予約履歴（相手管理）

[← 機能一覧に戻る](./README.md)

- ステータス: ✅ 実装済（基本機能）／✅ **手動の相手追加 実装済**（決定27・2026-06-19・プレミアム。要 `manual_contacts` テーブル適用）
- 対象プラン: 無料＝閲覧のみ／Pro＝メモ・印象スコア／プレミアム＝手動追加も可
- 仕様: [`../spec.md`](../spec.md) 主要機能 7（有料版機能）

## 概要

「相手管理」として、予約した相手の一覧・検索、面談メモ、印象スコアを管理する。

### 相手の登録方法のプラン差（決定27・2026-06-19）

- **無料・Pro＝会った人（予約者）のみ**（予約から自動登録）。無料は閲覧のみ、Pro はメモ・印象スコアを追加（[決定19](../open-decisions.md)）。
- **プレミアム＝ホストが手動で相手を追加できる**（予約していない見込み客なども登録）。✅実装済＝`manual_contacts` テーブル＋`manual-contact.js`（POST・`requirePremiumOwner` ガード）。`contacts.html` の `.premium-feature` 追加フォーム（`#manual-contact-form`）から登録し、`owner-bookings.js` が予約レコードと同形にマージして相手一覧（`#booking-list`）に表示（手動分は「手動追加」タグ）。未マイグレーション環境では `manual_contacts` クエリ失敗を握りつぶし空配列。

## 現状の実装

- `contacts.html`（相手管理）に実装:
  - 予約一覧（`owner-bookings`、最新50件、生年月日非公開はマスク）＋キーワード検索。
  - 面談メモフォーム（メール/キーワード/メモ/次のアクション）＝ `appointment-log`（保存・一覧）。
  - 印象スコア（第一印象・話し上手・聞き上手・積極性・ギバー度・前向きさ・論理性・共感力・決断力・紹介しやすさ）を5段階で記録。送信時にメモ末尾へ「【印象スコア】」として自動追記（`contacts.html` インラインスクリプト）。
  - 予約に紐づく「生年月日インサイト」を一覧表示（[16](./16-birthday.md)）。

## 関連ファイル

- `netlify/functions/owner-bookings.js` — 予約一覧

## 将来構想（打ち合わせ 2026-06-03）

- **AI 検索 / 顧客検索**: 登録ユーザーを属性（趣味・職種、例「ポーカー好き」「旅行好き」など）で検索し、こちらからアプローチできる機能。
- **ビッグデータ活用**: よく使われる質問のトップ5など、収集データの活用（[10](./10-questionnaire.md)）。
- 面談ログは「会話の内容」ではなく「この人と会った」という記録（内容メモは本人が任意で記す）。録音→議事録は将来のマスタープラン（[13](./13-plans.md)）。
