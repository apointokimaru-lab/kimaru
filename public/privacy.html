最終更新日: 2026年7月29日

一般社団法人ぴんころ（以下「当社」）は、日程調整サービス「キマル」（以下「本サービス」）における利用者の個人情報を、以下の方針に基づき取り扱います。

1. 取得する情報

アカウント情報（氏名、メールアドレス、ログイン方式）、Google 連携情報（プロフィール、許可された場合の Google カレンダーの空き時間・予定情報、予定作成・Google Meet 発行に必要な情報）、予約情報（予約日時、開催方法、事前アンケートの回答、任意・非公開選択可の生年月日）、利用記録（面談ログ、相手管理上のメモ・評価、アクセスログ、Cookie・セッション情報、サービス改善のための画面の閲覧記録＝表示した画面の種類・端末種別・言語・外部からの流入元ホスト名。生の URL と IP アドレスは保存しません）、AI連携情報（MCP連携の接続状態、接続を失効させるための識別子。利用者のAIサービスのアカウント情報は取得しません）、決済情報（決済代行事業者を通じて処理。当社はカード番号を保持しません）。

2. 利用目的

本サービスの提供（日程調整、カレンダー連携、予約管理、通知）、事前アンケート・生年月日に基づく関係構築支援、利用者が接続した外部AIサービス（MCP連携）を通じた面談準備の支援、不正利用の防止と招待コード（Cat Key）の適正運用、個人を特定しない形でのサービス改善・統計分析のために利用します。

3. 第三者提供・外部サービス

法令に基づく場合を除き、本人の同意なく第三者に提供しません。目的の範囲で以下の外部サービスを利用します。Google（OAuth／Calendar／Meet：認証・カレンダー連携・予定/Meet 発行）、Supabase（データベース・データ保管）、Square（有料プランの決済処理。カード情報は Square 側で処理）、Resend（予約確認・リマインダー等のメール送信）、Zoom（利用者がZoom連携を有効にした場合のみ：本人の認可に基づき、利用者自身のZoomアカウントでミーティングの作成・日程変更時の更新・キャンセル時の削除を行います。アクセストークンは暗号化して保管し、連携解除またはZoom側でのアプリ削除により遅滞なく削除します）。また、プレミアムプランのMCP連携では、利用者が接続した外部AIサービス（OpenAI の ChatGPT、Anthropic の Claude 等）へ、利用者の操作に基づいて予約情報・事前アンケート回答・プロフィール等の相手データが送信されます（詳細は「5. 外部AIサービス連携（MCP）における取り扱い」をご確認ください）。

4. Google ユーザーデータの取り扱い（Limited Use）

本サービスによる Google API から取得した情報の利用・転送は、Google API Services User Data Policy（Limited Use 要件を含む）に準拠します。カレンダー情報は本サービスの機能提供のためにのみ使用し、広告目的では利用しません。

5. 外部AIサービス連携（MCP）における取り扱い

プレミアムプランのMCP連携は、利用者ご自身が契約する外部AIサービス（OpenAI の ChatGPT、Anthropic の Claude 等）を本サービスへ接続する機能です。本連携において当社のサーバーでAI処理を行うことはなく、当社から自動的にデータを送信することもありません。送信は、接続後に利用者がAIサービス側で操作した時点で、その要求に応じてのみ行われます。送信される可能性がある情報には、予約者（ゲスト）の氏名・メールアドレス・事前アンケートの回答・面談メモ等、第三者の個人情報が含まれます。利用者は、これらの情報をご自身が選択した外部AIサービスへ送信することについて、必要な同意の取得を含め自らの責任で行うものとし、送信後の当該AIサービスにおける取り扱いについて当社は責任を負いません。本連携はプレミアムプランの利用者が明示的に接続した場合にのみ有効となり、本サービスの「AIアシスト」画面からいつでも解除できます（解除すると発行済みの接続はすべて無効になります）。接続には当社が発行する署名付きトークンを使用し、当社は利用者のAIサービスのアカウント情報を取得しません。予約者（ゲスト）の方は、ご自身の情報の開示・削除等について、下記のお問い合わせ窓口または面談相手である利用者へご請求いただけます。

6. 保管期間・削除

取得した情報はサービス提供に必要な期間保管します。利用者はアカウント削除を申請でき、削除時に関連情報を適切に消去します（法令上保管が必要なものを除く）。Google 連携はいつでも解除できます。アクセストークン等は暗号化して保管します。

7. 利用者の権利

本人からの請求により、保有個人データの開示・訂正・削除・利用停止に対応します。下記のお問い合わせ窓口までご連絡ください。

8. Cookie

ログイン状態の維持（セッション）に Cookie を使用します。サービス改善のための画面の閲覧記録には Cookie を使用せず、識別子は日ごとに変わる値へ変換して保存するため、日をまたいだ追跡は行いません。
