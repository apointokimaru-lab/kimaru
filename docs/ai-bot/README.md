## 2. 決まっていること

### プラン

| プラン | 先行100名 | 通常 | Bot 枠 | 同時Bot | 再要約 |
|---|---:|---:|---:|---:|---:|
| Pro | ¥980 | **¥2,200** | 月5時間 | 1台 | 会議あたり3回 |
| プレミアム | — | **¥4,800** | 月40時間 | 1台 | 会議あたり3回 |
| マスター | — | **¥9,800** | 月100時間 | 1台 | 会議あたり3回 |

- **先行価格は Pro のみ**。Pro＋プレミアムの合算が100人に到達したら、Pro の新規契約が ¥2,200 になる
- 先行価格は**解約後の再契約・プラン変更で失効**する
- **枠を使い切ったら Bot が会議から途中退出する**（マイナス残高・繰越は作らない）
- 1会議あたりの最大時間は設けない（内部安全タイムアウト4時間は異常停止用）

### 技術

| 項目 | 決定 |
|---|---|
| クラウド | AWS 東京。Bot は ECS Fargate（1会議1タスク） |
| キュー・起動 | SQS FIFO + DLQ / EventBridge Scheduler |
| 言語 | TypeScript 主軸、文字起こしのみ Python（faster-whisper） |
| DB | **Supabase 継続**（正式採用。RDS へは再評価トリガー成立時に移行判断） |
| 対象プラットフォーム | **Meet + Zoom 両対応**。Meet 先行（M1）→ Zoom 追加（M2以降） |
| 文字起こし | **自前のみ**。外部STT API は使わない。障害時は `deferred` で音声を14日保持し復旧後に自動再投入 |
| PoC の実行基盤 | Orchestrator・状態更新API・Reconciler・要約・クリーンアップは **Lambda**。Bot と STT のみ Fargate。**ALB・NAT・Redis は置かない** |

### 運用

- 開発者1名＋運営2名。**即時ページングは4種類のみ**（API 5xx継続／テナント越境／Bot 5件連続失敗／break-glass）
- 運営2名は AWS・DB に触らない。必要な操作は管理画面の機能として実装する
- **開発者不在時は縮退運転**（新規Bot起動を自動停止・稼働中は安全終了・既定7日・解除後の遡及起動なし）
- SLO 可用性 99.5%／RPO 1時間（PITR 有効化後）／RTO 平日9-18時は4時間・時間外は翌営業日中

### コスト

| 項目 | PoC | 本番（PITRあり） |
|---|---:|---:|
| 固定費（月額） | **¥4,500** | **¥32,800** |
| 変動費 | **¥40.58 / 課金対象1時間**（失敗コスト込み） | 同左 |

**損益分岐**: Pro先行45名／Pro通常18名／プレミアム11名／マスター7名（固定費 ¥32,800・満枠時）

## 4. レビューの経緯

`system-spec.md` は Claude Code が起案し、**Codex による批判的レビューを9ラウンド**かけて収束させた。

| 段階 | 結果 |
|---|---|
| v1.0 | 致命的10件・重要19件・軽微5件の指摘。判定「本番実装に入るべきでない」 |
| v1.1〜v1.9 | 原子性（Scheduler/SQS/ECS/DB）、リースの fencing、音声 manifest 検証、利用量の直列化、テナント境界、同意仕様、コストの二重計上などを順次修正 |
| **v2.0** | **判定「GO（実装着手可能）」**（M-1 の法務・規約確定を除く技術仕様として） |
| v2.1〜v2.4 | プラン変更・枠切れ退出・両プラットフォーム対応・要約テンプレート・残る未決定事項の決定を反映 |

**レビューで見つかった主な誤り**

- 収益試算が先行100名の据え置き価格を無視していた（売上 ¥323,000 → 正しくは ¥177,500）
- 音声 manifest の検証が無く、セグメント欠番に気づかず**音声を削除する経路**があった
- 失敗コストを二重計上していた（α に含めた上でさらに完了率で除算）
- ECS RunTask に `clientToken` がないと誤認していた（実際は存在し、これで起動の冪等性が根本解決した）
- 管理者MFA要件が現行の共有 `ADMIN_SECRET` 方式と矛盾していた
