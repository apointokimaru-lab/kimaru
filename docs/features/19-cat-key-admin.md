# 19. Cat Key 管理（運営）

[← 機能一覧に戻る](./README.md)

- ステータス: ✅ 実装済
- 対象: 運営（管理者）
- 仕様: 招待コード（[12](./12-invite-code.md)）運用の管理面

## 概要

運営が Cat Key 適用ユーザーを一覧・監査し、特典を取り消し/復元できる管理画面。

## 仕様（打ち合わせ 2026-06-03 / 不正利用対策）

無料利用が口コミで広がり、対象外まで無料が増えるのを防ぐ。

- **承認制**: Cat Key を入力しても即時に無料付与せず、**運営コンソールの画面で「承認」ボタンを押下**した場合のみ有効化する（決定 2026-06-03）。入力は「承認待ち」として記録され、運営が一覧から承認/却下する。これで不正利用をほぼ防げる。
- **状態管理**: 会員（メンバー）は「利用停止 / 利用再開」で一時停止・復帰でき、不正・退会時は「無料プランへ降格」で退会扱いにできる（`suspend`/`resume`/`demote`）。
- 「承認／却下」は Cat Key ログ画面で、「停止／再開／降格」はユーザー一覧で操作する。
- **将来**: Cat Key を定期更新（自動ローテーション）し、猫の集会のグループチャットから最新キーを取得する運用。退会者は旧キーが無効になり、より確実に防げる。

## 現状の実装

- 運営コンソール `cat-key-admin.html`（サイドメニュー型・ライトテーマ／青アクセント）。`/api/invite-apply?admin=cat-key` を呼ぶ。認証は `ADMIN_SECRET`（Bearer / `?secret=` / body.secret）。
- `GET`: オーナー一覧＋Cat Key イベント（`cat_key_events`）取得。
- **メンバー状態は既存列で表現**（`invite_code` を「メンバー(過去含む)」マーカーとして保持）。Cat Key ユーザーはプラン列に「**メンバー**」表示。

  | 状態 | 条件 | テーブルでの操作 |
  |---|---|---|
  | 申請中 | `cat_key_pending` | （一覧では操作なし → **Cat Key認証画面で承認/却下**） |
  | 利用中 | 下記以外（一般Free・課金・メンバー） | 利用停止（＋メンバーは無料プランへ降格） |
  | 停止中 | `cat_key_disabled` | 利用再開（＋メンバーは無料プランへ降格） |
  | 退会済 | `invite_code`有・`plan=free`・非凍結 | （操作不可） |

  ※ `invite_code` 有のユーザーはプラン列に「**メンバー**」表示。利用停止/再開は全ユーザー可、無料プランへ降格はメンバーのみ。停止/再開での plan 変更はメンバーのみ（非メンバーは `cat_key_disabled` だけ切替＝Square 課金者を誤って降格せず、再開でも昇格しない）。

- `POST` `{ owner_id, action }`: `approve` / `reject`（申請の承認・却下）, `suspend`（利用停止）, `resume`（利用再開）, `demote`（無料へ降格→`plan=free`・`invite_code` 保持で退会済）。`suspend`/`resume` はメンバー(`invite_code`有)のみ plan を `free`⇄`pro` 切替（非メンバーは `cat_key_disabled` のみ）。Pro 昇格で凍結データ復元、無料降格で超過データ凍結（決定15・#174）。
- **画面構成**: 「ユーザー一覧」（テーブル・列クリックでソート・状態別の操作）と「Cat Key認証」（**承認待ち一覧＝承認/却下**）、「操作履歴」をサイドメニューで切替。サイドメニューの「Cat Key認証」に**承認待ち件数バッジ**を表示。
- 適用・取消・無効コード等は `cat_key_events` に監査記録。

## 関連ファイル

- `public/cat-key-admin.html` — 管理 UI
- `netlify/functions/invite-apply.js` — 管理モード（`?admin=cat-key`）
- DB: `owners`（`cat_key_disabled` 等）、`cat_key_events`
