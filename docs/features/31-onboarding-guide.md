# 31. 初期設定の導線と使い方ガイド

対象: 発行者（ホスト）　状態: 実装済み（#353・2026-08-27）

## これは何か

登録直後の「何をすれば動き出すのか分からない」を解く2つの導線。

1. **初期設定カード** — ダッシュボード上部に出る3ステップのチェックリスト（進捗つき）
2. **使い方ガイド** — ヘッダーの「使い方ガイド」から開く、左右に送る紙芝居形式のModal

## なぜ必要か

「初期設定の方法がわかりにくい」というユーザーからの指摘。登録直後のダッシュボードは
「今日の予定（空）」「予約ページを共有（まだ無い）」「要対応」が並ぶだけで、**最初に何を
すればサービスが動き出すのか**が画面から読み取れなかった。

実際に詰まる順番は決まっている。カレンダーが未連携だと空き枠が正しく出ず、予約ページが
無ければ共有するURLも無い。この「使えない理由」が画面のどこにも出ていなかった。

## 1. 初期設定カード（ダッシュボード）

| ステップ | 完了の判定 | 導線 |
|---|---|---|
| ① Googleカレンダーと連携する | `/api/me` の `calendar_connected` | `/api/google-auth-start?connect=1`（設定画面を挟まず直接） |
| ② 予約ページを作る | `/api/booking-pages` の件数 ≥ 1 | `/booking-settings.html?new=1` |
| ③ プロフィールを設定する | `/api/profile` の基本7項目がすべて埋まっている | `/profile.html` |

### 決定事項

| 項目 | 決定 | 理由 |
|---|---|---|
| 達成状況の取得 | **既存の取得を使い回す**（新しいAPIを足さない） | ダッシュボードは既に `me` / `booking-pages` / `profile` を叩いている。カードのために往復を増やさない |
| 判定できないとき | **カードごと出さない**（3つとも判明するまで `hidden`） | 取得に失敗した項目を「未完了」と決めつけると、連携済みの人に「連携する」と出してしまう |
| 強調 | **次にやる1つだけ**を朱のボタンにする | 3つとも同じ強さで並ぶと、どれから手を付けるか分からない |
| ③の基準 | 「要対応」の**プロフィール未設定**と同じ（7項目すべて） | 2か所で基準が違うと「完了なのに要対応に出る」が起きる |
| 完了後 | 完了の行を出し、「閉じる」で以後は出さない（`localStorage: kimaru.setupDone`） | 済んだ人の画面を毎回占有しない。連携解除などで未完了に戻ったら再び出す |
| 保存先 | localStorage（DB列を足さない） | 端末ごとの表示の好みでしかなく、サーバに持つ理由がない |

## 2. 使い方ガイド（Modal・紙芝居）

`public/guide.js`。1枚＝1機能で、**図（実際の画面の見立て）＋「こんなとき」＋「使い方」**を並べる。
現在11枚（全体の流れ／カレンダー連携／予約ページ／受付時間とバッファ／事前アンケート／
プロフィール／共有／予約が入ったあと／相手管理／キャンセルと日程変更／プラン）。

- 送る手段: 左右のボタン・キーボード（←/→/Esc）・スワイプ・上部のセグメント（目次を兼ねる）
- 各枚の「この画面を開く」からその機能の画面へ飛べる
- `/dashboard.html#guide` のような直リンクでも開く

### 決定事項

| 項目 | 決定 | 理由 |
|---|---|---|
| 置き場所 | Edge Function（`auth-gate.js`）が**ログイン時だけ全HTMLに注入** | ヘッダーの「使い方ガイド」を全ページに配っている以上、開く先も全ページに要る。`usage.js` と同じで、30枚のHTMLに手で貼ると新しい画面が増えたときに漏れる |
| 図の作り方 | **インラインSVGの骨格**（スクリーンショットは使わない） | 画面を変えるたびに撮り直す運用は続かない。骨格なら画面の作りが変わらない限り古びない。画像ファイルも増えない |
| 図の中の文字 | **入れない**（数字と記号だけ） | 図に日本語を焼き込むと en / zh-TW でそこだけ日本語が残る |
| 文言の置き場所 | i18n.js（`guide.*` キー） | 3言語の対称性を既存のテストで担保できる。スライドとキーの対応は `scripts/test/unit.mjs` が固定 |
| ナビの折り返し | ログイン時だけ**ハンバーガーの境界を1180pxに広げる** | ナビが10項目になり、1180px 未満では言語選択とアバターが2段目に落ちてヘッダーからはみ出す（従来も1024px以下で起きていた）。未ログインは3項目なので900pxのまま |

## 関連ファイル

| `public/i18n.js` | `setup.*` / `guide.*`（ja / en / zh-TW） |
| `scripts/test/unit.mjs` | スライドと文言の対応・リンク先の実在 |
| `scripts/test/e2e.mjs` | カードの状態遷移・ガイドの送り／閉じる |

## 残る穴

- ガイドを開いた回数・どの枚で離脱したかは計測していない（`page_events` の `event` は
  `page_view` / `limit_hit` の許可リスト制。増やすならサーバ側の許可リストも触る必要がある）。
- ステップ②は「予約ページが1枚でもある」だけを見ており、受付時間が空のままでも完了になる。
